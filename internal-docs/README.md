# Internal docs (working material, not required reading)

This directory holds working material for contributors: specs, plans,
audits, the changelog (`progress.md`), architecture decision records
(`adr/`), and cleanup proposals. Judges and new users should start at
the root `README.md`, `VISION.md`, and `ARCHITECTURE.md` instead —
everything here is optional depth.

Nothing here is loaded at runtime; moving a file here only requires
fixing the link that pointed at it.
